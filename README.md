
# Trading Game

**Trading Game v1.0.0 - Free Edition**

A Windows desktop application.

## Download

Download the latest version from the [Releases page](../../releases).

### System Requirements

- Windows 7 32-bit (x86)
- Bundled Java 8 32-bit runtime
- Internet connection required only if the application itself requires it

### Installation

1. Download `TradingGame-Setup-v1.0.0-x86.exe` from Releases.
2. Run the installer.
3. Follow the installation instructions.
4. Launch Trading Game from the desktop shortcut.
